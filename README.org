* [[https://github.com/bitbloxhub][bitbloxhub]]'s flake template
  A flake template that uses:
  - [[https://github.com/hercules-ci/flake-parts][flake-parts]] to apply the NixOS module system to flakes.
  - [[https://github.com/vic/flake-file][flake-file]] for generating the =flake.nix=.
  - [[https://github.com/vic/import-tree][import-tree]] to simplify importing files.
    Also has [[https://github.com/andir/npins][npins]] compat!
  - [[https://github.com/numtide/treefmt-nix][treefmt-nix]] for formatting with src_bash{nix fmt}.
  - [[https://github.com/nicknovitski/make-shell][make-shell]] to merge devshell definitions from multiple files with the NixOS module system.
  - [[https://github.com/notashelf/flint][flint]] to check your flake inputs for duplicates.
  - [[https://github.com/NixOS/nixfmt][nixfmt]], [[https://github.com/astro/deadnix][deadnix]], and [[https://github.com/oppiliappan/statix][statix]]
    for linting and formatting your Nix code.
